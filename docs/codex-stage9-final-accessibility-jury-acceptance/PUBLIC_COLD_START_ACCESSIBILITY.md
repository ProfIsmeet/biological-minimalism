# Public cold-start accessibility

A public browser initially showed connecting/unavailable presentation before reaching connected PPG-DaLiA S14 and public read-only state. No false permanent source error was observed, but the run was not started from a controlled known-asleep backend, elapsed time was not instrumented, and exact VoiceOver speech was unavailable. Result: `PARTIAL`.

The public guide advises waiting up to roughly two minutes, avoiding repeated reloads, using explanatory routes during wake-up, then testing connection and reloading once if needed. No keep-alive workaround was added.
