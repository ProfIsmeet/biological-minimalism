# Stage 1B Expansion — Forbidden Claims

These claims must never appear in any future Stage-2 result document, dashboard
copy, Research Mode text, or paper draft, regardless of what any individual
experiment's numbers show.

- "IMU always improves HR." (GalaxyPPG/PPG-DaLiA support at most: IMU added
  information *in the datasets and protocols tested so far*, under a specific
  capacity-controlled comparison.)
- "EOG is necessary for sleep [staging]." (At most: EOG added information in
  the specific EEG-vs-EEG+EOG comparisons run on Sleep-EDF and, if replicated,
  HMC — never "necessary," never generalized beyond staging models built this
  way.)
- "Leg BioZ measures microgravity fluid shift." (QDE is a terrestrial
  treadmill-dehydration protocol. At most: bilateral leg impedance added [or
  did not add] information about *exercise-induced, treadmill-protocol,
  baseline-relative body-mass change* in this specific n=10 cohort.)
- "LBNP validates astronaut hypovolemia monitoring." (At most: thoracic EIS
  added [or did not add] information about *externally-imposed LBNP stage* in
  a ground-based, non-spaceflight, n≤16 cohort.)
- "Four EEG channels capture cognition." (At most: the frozen sparse
  AF7/AF8/TP9/TP10 subset did [or did not] retain comparable *digit-span
  memory-load classification* information relative to the full 63-channel
  montage, in this specific dataset and task.)
- "Full EEG is unnecessary globally." (Same scope limitation as above — a
  single task, single dataset, single frozen channel subset.)
- "These datasets prove a final four-sensor architecture." (No combination of
  independent single-modality replications proves a joint architecture;
  none of these experiments trains or evaluates the full fusion model.)
- "More datasets prove global Pareto optimality." (Additional replications
  narrow uncertainty about specific marginal-value questions; they do not
  establish that any particular sensor combination is Pareto-optimal across
  the mission's full objective space — Pareto/architecture work remains
  `NOT_READY` per the governing project state and is untouched by Stage 1B.)
- "Public terrestrial validation equals spaceflight validation." (None of
  these five datasets involve microgravity, spaceflight analogs beyond LBNP's
  hypovolemia model, or astronaut subjects. Every claim from every one of
  these experiments is bounded to its own terrestrial population and
  protocol.)
- "GalaxyPPG/HMC/LBNP/ds003838 replicate the original result." (A second
  dataset showing the same direction is *consistent with*, not proof of, the
  original finding — especially with small/moderate cohorts. Use "did not
  contradict" / "reproduced under an independent protocol," not "replicated
  and confirmed" language, per this project's established negative-result and
  small-N discipline.)
- "The EIS spectrum is a continuous real-time signal." (It is a per-stage
  snapshot, roughly 1 spectrum/minute against ~5-minute stages — see
  `results/dataset_expansion_rate_provenance_stage1b.json`.)
- "Resp[iration]/EIS/any spectroscopy excitation frequency is a sampling
  rate." (The H2-driven distinction — excitation frequency axis vs temporal
  acquisition cadence vs native signal sampling rate — applies to every
  dataset in this manifest, not just Sleep-EDF.)
